<h1 style="color:#483B91;">TEMUCORD</h1>

(Parte GABO)

<h3 style="color:#483B91;">Tecnologías</h3>

+ Backend: Laravel 12  
+ Frontend: React / Livewire  
+ API: Laravel (para manejar usuarios, mensajes, servidores, etc.)  
+ Base de datos: PostgreSQL  
+ Servidor: Apache  

<h3 style="color:#483B91;">Funcionalidades principales (tipo Discord)</h3>

+ Registro e inicio de sesión  
+ Sistema de usuarios  
+ Creación de servidores  
+ Creación de canales  
+ Envío de mensajes en tiempo real  
+ Roles y permisos dentro de servidores  
+ Lista de usuarios conectados  
+ Historial de mensajes  

<h3 style="color:#483B91;">Requisitos técnicos</h3>

+ Uso de Eloquent (OBLIGATORIO)  
+ No usar Raw Queries  

Uso de:
+ Migraciones  
+ Modelos  
+ Seeders  

Validaciones:
+ Backend (Laravel)  
+ Frontend (JS/TS)  

<h3 style="color:#483B91;">Interfaz</h3>

+ Tailwind CSS  
+ Diseño responsivo  

Layout tipo:
+ Sidebar (servidores)  
+ Canales  
+ Chat principal
