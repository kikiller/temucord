# Temucord - Aplicación tipo Discord

Temucord es una plataforma de comunicación en tiempo real que permite a los usuarios crear servidores, organizar canales y compartir contenido multimedia. Este proyecto está construido con una arquitectura moderna utilizando Laravel 12 para el Backend y React para el Frontend.

## 🚀 Caracteristicas del Sistema

* **Servidor Web:** Apache
* **Lenguaje:** PHP 8.2+ (Laravel 12)
* **Base de Datos:** PostgreSQL
* **Frontend:** React con Tailwind CSS
* **Manejador de Paquetes:** Composer y NPM


## 📋 Características Principales

* **Autenticación Completa:** Registro, Login y 2FA gestionado con Laravel Fortify.
* **Roles y Permisos:** Sistema basado en Eloquent para diferenciar Administradores Globales, Creadores y Miembros.
* **Servidores y Canales:** Creación de servidores dinámicos con canales abiertos y cerrados.
* **Multimedia:** Soporte para envío de imágenes, audios y videos.
* **Reportes:** Sistema de moderación para canales inapropiados.
